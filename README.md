# پرک (Parak)

سایت معرفی **پرک**؛ برند ایرانی پوشاک دست‌دوز نوزاد و باکس هدیه — همراه با یک دستیار چت هوشمند که از طریق [OpenRouter](https://openrouter.ai) به سوال مشتری‌ها جواب می‌دهد.

## اجرا

پیش‌نیاز: [Node.js](https://nodejs.org) نسخه‌ی ۲۰٫۱۲ یا جدیدتر. هیچ بسته‌ای لازم نیست نصب شود.

۱. فایل `.env.example` را کپی کنید و اسمش را `.env.local` بگذارید.
۲. کلید OpenRouter را جلوی `OPENROUTER_API_KEY=` بنویسید:

```
OPENROUTER_API_KEY=sk-or-v1-...
```

۳. سرور را اجرا کنید:

```
npm start
```

۴. در مرورگر به `http://localhost:3000` بروید.

برای توسعه، `npm run dev` سرور را با هر تغییر در `server.js` خودکار ری‌استارت می‌کند.

> اگر `index.html` را مستقیم (با دوبار کلیک) باز کنید، سایت دیده می‌شود اما چت‌بات کار نمی‌کند؛ چت‌بات به سرور نیاز دارد.

## ساختار

| فایل | کاربرد |
|---|---|
| `parak-site/index.html` | خود سایت (HTML، CSS و JS همه در یک فایل) + پنجره‌ی چت |
| `parak-site/images/` | عکس‌های سایت |
| `parak-site/index-artifact.html` | نسخه‌ی تک‌فایلی سایت با عکس‌های داخلی (بدون چت‌بات) |
| `server.js` | سرور: سایت را نمایش می‌دهد و پیام‌های چت را به OpenRouter می‌فرستد |
| `.env.example` | نمونه‌ی تنظیمات؛ مقادیر واقعی در `.env.local` (که در git ثبت نمی‌شود) |

## تنظیمات (`.env.local`)

| متغیر | ضروری | توضیح |
|---|---|---|
| `OPENROUTER_API_KEY` | بله | کلید OpenRouter |
| `OPENROUTER_MODEL` | خیر | مدل هوش مصنوعی؛ پیش‌فرض `anthropic/claude-haiku-4.5` |
| `PORT` | خیر | پورت سرور؛ پیش‌فرض `3000` |
| `SITE_URL` | خیر | آدرس عمومی سایت بعد از انتشار |

## چت‌بات

- کلید API فقط روی سرور است و هرگز به مرورگر فرستاده نمی‌شود.
- اطلاعاتی که ربات به آن تکیه می‌کند (محصولات، قیمت‌ها، زمان ارسال، مرجوعی، راه‌های تماس) در `SYSTEM_PROMPT` داخل `server.js` است. **هر وقت قیمت یا شرایط سایت عوض شد، آنجا را هم به‌روز کنید.**
- برای محافظت از اعتبار OpenRouter، هر بازدیدکننده حداکثر ۲۰ پیام در ساعت می‌تواند بفرستد (`RATE_LIMIT` در `server.js`).

## انتشار

سایت باید روی سرویسی منتشر شود که Node.js اجرا می‌کند (مثل Render یا Railway). دستور اجرا `npm start` است و `OPENROUTER_API_KEY` (و در صورت نیاز `SITE_URL`) را در بخش Environment Variables آن سرویس تنظیم کنید — نه داخل فایل‌های پروژه.
